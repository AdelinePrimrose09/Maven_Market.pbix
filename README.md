
# Maven Market Power BI Dashboard

This project presents an interactive Power BI dashboard built to analyze customer insights and sales performance using data from Maven Market.

## 🧾 Project Overview

The dashboard provides a detailed view of customer demographics and purchasing trends. It's designed to help stakeholders make better decisions using data-driven insights.

## 📊 Key Features

- **Customer Summary Cards**
  - Total Customers
  - Homeowners vs Non-Homeowners
  - Customers With Children

- **Customer Segmentation**
  - Distribution by State and City
  - Gender and Homeownership Breakdown

- **Age Analysis**
  - Age Distribution Histogram
  - Segmentation into age groups (18–25, 26–35, etc.)

- **Revenue Insights**
  - Top 10 Customers by Revenue
  - Revenue by Age Group and Gender

- **Cashbook Drilldown**
  - Transaction-level view (if applicable)
  - Running balances and credit/debit simulation

## 🛠 Tools & Technologies

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling and Relationships
- Custom Slicers and Visual Interactions

## 🧠 How to Use

1. Clone this repository or download the files.
2. Open the `Dashboard.pbix` file in **Power BI Desktop**.
3. Use the filters and visuals to explore the data.
4. Customize or extend based on your own dataset.
